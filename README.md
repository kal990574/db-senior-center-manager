# 🏠 경로당 관리 시스템 (Senior Center Management System)

Java와 PostgreSQL을 기반으로 구축된 경로당 관리 시스템입니다.  
예약, 게시판, 리뷰 등 경로당 운영에 필요한 주요 기능을 포함하고 있으며, JDBC를 통해 데이터베이스와 연동됩니다.

---

## 📌 프로젝트 개요

- Java 애플리케이션과 PostgreSQL을 연동하여 실사용 가능한 백엔드 시스템 구현
- 경로당 예약, 리뷰 게시판 등의 핵심 기능 개발
- 예약 시스템에 효율적인 알고리즘 적용
- 사용자 요청에 따라 데이터를 생성, 조회, 수정, 삭제(CRUD) 처리

---

## 🔹 구현 기능

### ✅ 1. 데이터베이스 연동 (JDBC)
- JDBC(Java Database Connectivity)를 활용하여 Java와 PostgreSQL을 연결  
- SQL 쿼리를 통해 사용자 요청 처리 및 데이터 저장/조회/수정 수행  
- 예외 처리 및 연결 안정성 확보

### ✅ 2. 경로당 예약 기능
- 예약 가능한 경로를 효율적으로 관리하는 알고리즘 구현  
- 경로당 별 예약 현황 관리 및 중복 방지  
- 예약 등록/해제 기능 제공

### ✅ 3. 리뷰 및 게시글 CRUD 기능
- 게시판 형태의 리뷰 및 공지사항 기능 구현  
- Create, Read, Update, Delete 로직을 기반으로 한 게시글 관리  
- 데이터베이스 테이블과 연동된 동적 처리

---

## 🛠 사용 기술

- **언어**: Java  
- **데이터베이스**: PostgreSQL  
- **연동 기술**: JDBC  
- **기능 구현**: 예약 시스템 알고리즘, 게시판 CRUD, 예외 처리 등
